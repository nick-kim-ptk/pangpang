# 팽팽이 — 말하면서 익히는 중국어

HSK 4급 수준의 생활 회화를 **음성으로 답하며** 반복 연습하는 웹앱이에요.
GitHub Pages(호스팅) + Supabase(Google 로그인·학습 기록)로 돌아가고, 서버 코드는 없어요.

## 이렇게 동작해요

1. **오늘의 레슨** — 하루 한 과(총 50과). 오늘 배울 내용을 설명으로 읽고, 단어(한자·병음·뜻)를 보고 들은 뒤, 질문에 음성으로 답해요. 한 번에 50문제씩, 레슨의 문장을 섞어 반복해서 연습해요. (한국어 뜻은 ‘뜻 보기’를 눌러야 보여요. 이미 모든 문장을 한 번씩 풀었다면 중간에 끝내도 기록이 저장돼요.)
2. **채점** — 말한 내용을 중국어로 인식해서, 그 레슨의 핵심 표현(예: `喜欢`)을 썼는지 확인해요.
   - 틀리면 다시 말하기 → 2번 틀리면 정답과 병음·뜻을 보여주고 따라 말하기
   - 전부 맞힐 때까지 같은 질문이 계속 돌아와요
3. **복습** — 한 번에 맞힌 문제는 1·3·7·14·30일 간격으로, 틀린 문제는 다음 날 다시 나와요. 레슨별 복습·랜덤 복습도 있어요.
4. **레슨 탭** — 50개 레슨 전체 목록. 원하는 레슨을 골라 미리 배우거나 다시 연습해요. (홈에는 오늘의 레슨과 복습만 나와요.)
5. **단어장** — 배운 레슨의 단어가 누적돼요. 눌러서 발음을 들을 수 있어요.
6. **마이페이지** — 닉네임 수정(홈에서 “닉네임님, 오늘도 화이팅하세요!”로 불러 줘요), 배운 레슨·단어, 최근 7일 학습 기록, 로그아웃.
7. **오늘의 한 문장** — 홈에 하루 한 문장이 나와요. 문장은 `phrases.js`에서 고치거나 늘릴 수 있어요. 닉네임은 Supabase 로그인 정보(user_metadata)에 저장돼서 따로 테이블을 만들 필요가 없어요.

> 음성 인식은 브라우저 기능(Web Speech API)을 써요. **Android Chrome / 데스크톱 Chrome·Edge / iPhone Safari**에서 동작하고,
> 지원하지 않는 브라우저에서는 자동으로 키보드 입력으로 바뀌어요.

## 설정 (처음 한 번, 약 15분)

### 1. Supabase 프로젝트 만들기
1. [supabase.com](https://supabase.com) → New project
2. 왼쪽 **SQL Editor** → New query → `supabase.sql` 내용을 붙여넣고 **Run**
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사해 `config.js`에 붙여넣기
   (anon 키는 공개돼도 괜찮아요. `service_role` 키는 절대 넣지 마세요.)

### 2. Google 로그인 켜기
1. [Google Cloud Console](https://console.cloud.google.com) → 프로젝트 선택 → **API 및 서비스 → OAuth 동의 화면** 설정 (외부, 이메일·프로필만)
2. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기** → 유형 `웹 애플리케이션`
   - **승인된 리디렉션 URI**: `https://<프로젝트ID>.supabase.co/auth/v1/callback`
     (Supabase → Authentication → Sign In / Providers → Google 화면에 이 주소가 보여요)
3. 만들어진 `클라이언트 ID`와 `클라이언트 보안 비밀`을 Supabase **Authentication → Providers → Google**에 붙여넣고 Enable

### 3. GitHub Pages로 올리기
1. 새 저장소를 만들고 이 폴더의 파일을 모두 올리기 (`config.js`에 값 입력 후)
2. 저장소 **Settings → Pages → Branch: main / root → Save**
3. 주소가 `https://<아이디>.github.io/<저장소>/` 로 나와요

### 4. 마지막: 로그인 후 돌아올 주소 등록
Supabase **Authentication → URL Configuration**
- **Site URL**: 위 GitHub Pages 주소 (끝에 `/` 포함)
- **Redirect URLs**: 같은 주소 추가. 로컬 테스트용으로 `http://localhost:8000/` 도 추가하면 편해요.

이걸 빠뜨리면 로그인 후 엉뚱한 주소로 돌아가요.

(마이크는 `https` 또는 `localhost`에서만 켜져요.)

## 레슨 추가하기
`lessons.js`의 `LESSONS` 배열에 객체를 하나 더 넣어요. 기존 레슨을 그대로 복사해서 고치는 게 가장 쉬워요.

```js
q('你喜欢喝咖啡吗？', 'Nǐ xǐhuan hē kāfēi ma?', '커피 마시는 걸 좋아해요?',   // 질문 (중국어·병음·뜻)
  '我喜欢喝咖啡。', 'Wǒ xǐhuan hē kāfēi.', '저는 커피 마시는 걸 좋아해요.',    // 예시 답안
  [['喜欢']])                                                                  // 꼭 들어가야 할 표현
```
- `must`의 안쪽 묶음은 "이 중 하나", 묶음끼리는 "모두"예요. `[['喜欢'], ['茶','咖啡']]` → `喜欢`과 `茶/咖啡` 중 하나가 모두 들어가야 통과.
- 레슨에는 `intro`(오늘의 레슨 카드에 나오는 설명 문장)도 넣어요. 레슨 순서는 `lessons.js` 아래쪽 `ORDER` 배열에서 정해요.
- 레슨 `id`는 한 번 정하면 바꾸지 마세요. 학습 기록이 이 id에 묶여 있어요.
- 한글 독음은 병음에서 자동으로 만들어져요. 병음만 정확히 적으면 돼요.
- 한자 수준을 올리고 싶으면 `must`를 더 엄격하게 쓰면 돼요.

## 알아두면 좋은 점
- 채점은 "정해진 표현을 썼는지" 기준이라, 문법이 완벽한지까지는 판단하지 않아요. 발음이 어색하면 음성 인식이 다른 글자로 들어서 틀림 처리될 수 있어요 — 그게 곧 발음 피드백이 돼요.
- 인식된 글자가 계속 어긋나면 `grade.js`의 `check`에서 허용 표현을 `must`에 더 추가하세요.

## 새로 들어간 기능

- **변형 문제**: 연습 2바퀴째부터 단어를 바꾼 비슷한 문제가 섞여 나와요 (`variants.js`). 예: 咖啡 → 茶, 日语 ↔ 英语.
  뜻이 어색해지는 경우(날짜·시각·짝이 있는 말)는 일부러 만들지 않아서, 전체 문제의 약 15%에만 변형이 있어요. 단어 묶음은 `variants.js` 맨 위 `GROUPS`에 추가하면 늘어나요.
- **약한 문제 집중 연습**: 복습 탭. 틀린 적이 있고 아직 익숙하지 않은 문제를 20문제씩 모아서 풀어요.
- **하루 목표 · 축하**: 마이페이지에서 20/50/100 문제 중 선택. 목표를 채우거나 3·7·14·30·50·100일 연속 학습이면 축하 화면.
- **다크 모드**: 마이페이지 → 화면 (자동/라이트/다크).
- **앱 설치(PWA)**: `manifest.webmanifest` + `sw.js`. HTTPS(GitHub Pages)에서 마이페이지에 설치 버튼이 나타나요. iOS는 Safari 공유 → 홈 화면에 추가.

## 복습 알림 켜기 (웹 푸시) — 직접 확인이 필요해요

Supabase 로그인을 연결한 뒤에만 동작해요. 아직 실제 기기에서 테스트하지 못했어요.

1. 키 만들기: `npx web-push generate-vapid-keys` → 공개 키는 `config.js`의 `VAPID_PUBLIC_KEY`에.
2. `supabase.sql`의 5번(테이블)을 실행해요.
3. 함수 올리기: `supabase functions deploy send-reminders --no-verify-jwt`
   비밀 값: `supabase secrets set VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:내메일 CRON_SECRET=아무_긴_문자열`
4. `supabase.sql` 6번의 cron 주석을 풀고 `<PROJECT_REF>`, `<CRON_SECRET>`을 바꿔 실행해요 (15분마다 호출).
5. 앱을 홈 화면에 설치한 뒤 마이페이지 → 복습 알림 → 켜기. iPhone은 iOS 16.4 이상, 홈 화면에 추가한 앱에서만 알림이 와요.
오늘 이미 공부한 사람에게는 알림을 보내지 않아요.

## 효과음 · 이어하기

- **효과음**: 파일 없이 브라우저가 소리를 직접 만들어요 (`app.js`의 `sfx`). 정답(연속 정답일수록 음이 올라가요)·오답·마이크·완료·목표 달성 소리와 진동이 있고, 마이페이지 → 효과음·진동에서 끌 수 있어요.
- **중간 저장**: 연습 중 나가면 푼 문제까지의 기록이 바로 저장돼요 (복습·약한 문제에 반영). 레슨 완료 처리는 모든 문제를 한 번씩 풀었을 때만 돼요.
- **이어하기**: 같은 레슨을 다시 열면 "이어서 할까요?"가 나와요. 이어하기 위치는 그 기기에만 저장돼요 (서버에는 올라가지 않아요).
